# 🌐 Web and Mobile Technologies – Practical Labs

This repository contains practical laboratory exercises and web development projects completed as part of the Web and Mobile Technologies (WMT) module at the Sri Lanka Institute of Information Technology (SLIIT).

The coursework focuses on frontend web development using HTML, CSS, JavaScript, and React.

## 🧪 Laboratory Contents

| Lab | Topics Covered |
|---|---|
| Lab 01 | HTML fundamentals and webpage development |
| Lab 02 | CSS styling and webpage design |
| Lab 03 | HTML, CSS and JavaScript practical exercises |
| Lab 04 | JavaScript programming exercises |
| Lab 05 | HTML and JavaScript webpage development |
| Lab 09 | React fundamentals, JSX, components and Vite |

## 🚀 Running the React Project

1. Install [Node.js](https://nodejs.org/).
2. Navigate to the React project directory.
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in the terminal.
